# Rust TV

Een rustig startscherm voor de Samsung-tv: lucht die met de dag meekleurt,
klok, weer in Wevelgem en alleen je eigen tegels.

- Pijltjes: kiezen · OK: openen
- OK ingedrukt houden op een tegel: verplaatsen (◀ ▶), verwijderen (▼), klaar (OK)
- "Alle apps": OK = openen · OK ingedrukt = op je startscherm zetten of eraf halen
